# Implementation status

**Purpose: DETAILED PROJECT EXECUTION LEDGER**

Owns:

- completed work;
- current implementation state;
- deferred work;
- validation history / evidence;
- known defects;
- risks;
- blockers;
- implementation notes.

Does **not** own next approved action.

```text
What am I allowed to do next?
        → .ai/handoff.md only
```

Read [`.ai/handoff.md`](../../handoff.md) for continuation authority. This ledger must not compete with it. Do not create `cursor-status.md`, `chatgpt-handoff.md`, or other tool-private status files.

Update this file **when an active project exists and the milestone applies**. Generic template milestones (no active project) do not invent a project workspace just to write a ledger.

If this ledger says work is done and Git/tests/config disagree:

```text
SURFACE DISCREPANCY
```
