# Skills

Skills are **reusable engineering procedures** for humans and AI tools using this repository.

They are **not** runtime capabilities. They do not add MCP, tools, LangGraph features, or application ports.

Only **recurring** procedures belong here. Do not add a framework-specific skill merely because the seed depends on that framework.

There is one shared `.ai/` workspace. Skills do not get a private handoff.

## Current skills

| Skill | When to use |
| --- | --- |
| [`architecture-review.md`](architecture-review.md) | Before approving project or template architecture |
| [`implementation-planning.md`](implementation-planning.md) | Before authorizing a Cursor (or other executor) milestone |
| [`cursor-review.md`](cursor-review.md) | After implementation, before APPROVE or CORRECTION-ONLY |

## Reading

Use a skill when the current milestone or review needs that procedure. A fresh session does not need to read every skill. Start from [`.ai/README.md`](../README.md) and [`.ai/handoff.md`](../handoff.md).
